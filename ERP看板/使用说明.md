# 库存采购异常看板使用说明

## 1. 打开方式

内网访问地址：`http://[INTERNAL_IP]:8088/`

电脑和手机可以打开同一个地址。手机需要连接可以访问公司内网的网络。

## 2. 页面功能

- “采购异常”：查看采购数量不足、采购订单延期和补货通知。
- “库存异常”：查看零库存、低于补货规则和待入库等异常。
- 顶部等级筛选：按 P0/P1/P2/P3 筛选。
- 分类按钮：只看某一种异常。
- 搜索框：输入产品编号、名称或条码，至少 2 个字符后查询。
- “刷新”：立即从 Odoo 重新读取；页面也会每 3 分钟自动刷新。
- “使用说明”：打开页面内帮助。
- 全屏按钮：进入或退出全屏。

## 3. 色块操作

- 点击色块可查看 Odoo 依据和建议动作。
- 右上角 `×` 只在当前浏览器隐藏色块，不会删除或修改 Odoo。
- 人工隐藏刷新后仍保持，但换电脑不会同步。
- 点击“恢复已忽略”可以恢复当前浏览器隐藏的色块。
- 普通异常在 Odoo 数据恢复正常后，会在下一次刷新自动消失。

## 4. 补货通知

补货通知直接来自 Odoo“库存 → 补货”的手动补货记录。

色块显示：产品编号、名称、规格型号、供应商、当前库存、补货数量和单位。当前库存与产品搜索使用同一个 Odoo 总在手库存口径。

### 采购人员

采购完成后点击色块中的“已补货”。按钮保存后不能重复点击，服务器会把这条记录标记为等待入库。这个操作只写看板本地状态，不修改 Odoo。

### 仓库人员

采购端点击“已补货”后，库存看板中同一产品显示“待入库”。两边使用同一个内网地址时可以同步。

### 自动消失

满足任一条件后，采购和库存两个看板中的补货色块会在刷新后同时消失：

1. 已点击“已补货”，并且 Odoo 补货数量变为 0。
2. 入库后在手库存增加量大于或等于原补货数量。
3. Odoo 手动补货列表已经没有这条记录。

部分入库但未达到原补货数量时，色块继续保留。

## 5. 数据说明

- 看板只读 Odoo，不会新增、删除、确认、审批或入库。
- 当前库存直接读取 Odoo 产品总在手库存。
- 规格型号直接读取 Odoo 补货行规格字段。
- 补货数量直接读取 Odoo 补货数量，不由看板推算。
- 供应商优先读取补货行供应商，缺失时使用采购数据中的供应商映射。
- 最后同步时间显示本次 Odoo 数据更新时间。

## 6. 常见问题

### Odoo 已申请补货，看板没有出现

点击“刷新”，并确认 Odoo 记录属于手动补货。自动刷新最长等待约 3 分钟。

### 已入库但色块没有消失

点击“刷新”，核对 Odoo 总在手库存、补货数量，并确认采购端是否点击过“已补货”。部分入库不会提前消失。

### 两台电脑状态不同

两台电脑必须都打开 `http://[INTERNAL_IP]:8088/`。人工点击 `×` 的隐藏状态只在当前浏览器保存，不会同步；“已补货”和“待入库”状态会通过服务器同步。

### 库存数字和 Odoo 不一致

先按 `Ctrl+F5` 强制刷新，再点击页面“刷新”。仍不一致时记录产品编号和截图，交给维护人员核对 `product.product.qty_available`。

### 页面打不开或显示未连接

确认电脑或手机在可访问公司内网的网络中，然后联系维护人员检查看板服务和 Odoo 连接。
