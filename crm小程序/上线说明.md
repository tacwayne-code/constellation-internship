# CRM 前端上线说明

## 当前工程类型

业务页面是 React + Vite H5，`wechat-miniapp/` 是可导入微信开发者工具的原生小程序入口，通过 `web-view` 打开部署后的 H5。H5 目录不能直接作为小程序代码上传；上传时应导入 `wechat-miniapp/`。

## 交接压缩包用途

- `crm-miniapp-web-server-20260721-handover-final.zip`：项目交接包，同时包含 H5 源码与构建产物、Python 后端、微信小程序入口、测试、部署脚本和说明文档。
- 交接包不包含 `node_modules`、真实业务数据、生产密钥、HTTPS 证书或 Git 历史。前端依赖通过 `npm ci` 恢复；生产数据和密钥必须通过公司安全渠道另行交接。
- 完整接手说明见根目录 `项目交接说明.md`。

## 小程序上线所需后续工作

1. 将 H5 和 Python 后端部署到已备案的 HTTPS 域名。
2. 修改 `wechat-miniapp/project.config.json` 的 AppID 和 `wechat-miniapp/config.js` 的域名。
3. 在微信公众平台配置 `request 合法域名` 和 `业务域名`，再使用微信开发者工具导入 `wechat-miniapp/` 并上传。

当前页面访问 `/api` 接口，因此正式环境还需要部署 `server` 后端，并让站点反向代理 `/api` 到后端服务。
