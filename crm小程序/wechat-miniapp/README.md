# 微信开发者工具导入说明

在微信开发者工具中选择“导入项目”，目录选本文件夹。这个小程序没有注册和密码登录：员工打开后自动校验微信身份，首次使用只需点一次“验证公司员工身份”。

正式上传前只需配置：

1. 把 `project.config.json` 中的 `appid` 改为公司的小程序 AppID。
2. 把 `config.js` 中两个地址改为 CRM 的备案 HTTPS 域名。
3. 在微信公众平台把该域名配置为 `request 合法域名` 和 `业务域名`。

服务器私有环境文件还要填写 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`。AppSecret 不得放进 H5 或本小程序目录。

正式启用时不需要预置管理员名单。第一个完成微信手机号验证和实名注册的账号会自动成为销售经理并直接进入系统；后续账号提交角色申请后，由该经理审批。

其他员工首次进入时验证手机号、填写姓名并申请角色。老板在 CRM 首页的“人员待审核”中确认最终角色，无需提前上传完整人员名单。手机号是员工唯一标识，微信身份只作为登录绑定凭证。
