# 拜访行程与路费测试模块

## 位置

- 项目目录：交接包解压后的 `crm-miniapp-web`
- 模块代码：`src\trip`
- 测试入口：`http://127.0.0.1:5173/?module=trip`
- 原 CRM 入口：`http://127.0.0.1:5173/`

该模块与 CRM 在同一个项目中，通过独立入口测试，不会改动现有客户、拜访和销售单流程。验证通过后再把行程结果接入正式拜访记录。

## 启动模拟版

未配置高德 Key 时，系统自动使用模拟路线，适合先检查页面和上报流程。模拟版不会生成真实高速费。

终端一：

```powershell
cd <交接包解压目录>\crm-miniapp-web
npm run api
```

终端二：

```powershell
cd <交接包解压目录>\crm-miniapp-web
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/?module=trip`，点击“填入测试路线”，再点击“计算往返里程与路费”。

## 启动高德实时版

先在高德开放平台创建应用并申请 **Web 服务** Key。Key 只配置在后端，不要写进前端代码。

终端一：

```powershell
cd <交接包解压目录>\crm-miniapp-web
$env:AMAP_WEB_SERVICE_KEY="你的Web服务Key"
npm run api
```

终端二仍运行 `npm run dev`。页面结果右上角显示“高德实时”才代表正在使用真实高德路线；显示“模拟估算”说明后端没有读取到 Key。

## 当前数据范围

- 自动计算：出发地、多个客户目的地、返程地之间的全部路线段，以及全程里程、预计时长和高德返回的路线收费金额。
- 人工核对：路线计算完成后统一核对最终里程、实际油费、实际高速费和调整说明。油费只由销售手动填写，不自动估算；未走高速时实际高速费填 0。
- 行程报销单：通过 `/api/expense-reports` 写入服务器共享数据文件；员工只查看本人记录，销售经理可以查看并审批。正式使用前仍需在公司环境验证备份和权限配置。
- H5 定位：浏览器定位坐标会转换为高德 GCJ-02 坐标，并通过逆地理编码同步更新地点名称和完整地址；需要浏览器授予定位权限。
- 微信小程序接入：使用 `wx.getLocation({ type: "gcj02" })` 获取位置，并继续调用服务器路线接口。高德 Key 仍放在服务器。

高德收费金额适合作为报销预估，不应当作最终财务凭证。实际 ETC 优惠、临时绕行、收费政策变化等情况，由销售修改后再确认上报。
