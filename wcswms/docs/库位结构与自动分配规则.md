# 库位结构与自动分配规则（WMS 1.5.0）

分配规则入口：库位管理 → 分配规则。

单双伸及货架尺寸入口：库位管理 → 选择左仓或右仓 → 设置总层列数。两个入口独立保存。

## 单双伸结构

“库位结构”统一在总层列数窗口设置。选择单伸时，每个层列位置一个库位；选择双伸时，每个层列位置包含前排单伸和后排双伸两个库位。

平面图同时显示前后排，分别点击查看物料或管理状态；库位编号继续使用“仓侧-层-列”，伸位单独标示。“新增层列位置”沿用该仓结构，补齐缺少的库位，不再另选伸位。入出库页面也不增加伸位选择。

缩小范围或由双伸改为单伸时，有库存或未结束任务的库位不能停用。手工停用的库位不会因保存总层列数而恢复。现场核对勾选项只作用于新增及随范围恢复的库位。

## 分配规则

左右仓共用一套规则，可随时修改，保存后对后续新建任务立即生效，无需再次重启服务；不会调整已有任务、库存或库位尺寸。

| 左右分配方式 | 实际行为 |
| --- | --- |
| 先左后右 | 左仓的可用库位分配满后，再分配右仓 |
| 先右后左 | 右仓的可用库位分配满后，再分配左仓 |
| 均分 | 左、右、左、右交替分配 |

先确定仓侧，再按“仓内优先级”选择先层数再列号，或先列号再层数。上下支持先下后上／先上后下，前后支持先前后后／先后后前；前是小列号，后是大列号。层列顺序不会让系统提前跳到另一仓。

“分配满”指该仓没有符合条件的可用候选：占用、预留、停用、未核对及双伸通道阻挡都会使库位暂时不可分配。自动配空箱也先用完优先仓内符合条件的空箱，再从另一仓选择。

切换到均分时从左仓开始；每次成功的自动选空位或自动配空箱共用同一交替进度，下一次优先对侧。若某侧没有可用候选，则使用另一侧，下一次仍先尝试缺少候选的那侧。进度随任务事务持久化，重启后接续；失败批次、重复请求不消耗轮次。手选目标、人工选择已有物料箱、原位返库不改变轮次。取消已分配任务不回退轮次。

修改均分下的仓内方向或重复保存相同规则，不重置轮次；离开均分后重新选择均分，才重新从左仓开始。

已保存的旧版左右方向及上下前后方向会保留；旧版六种优先级自动保留层列的相对先后，并将左右策略置于仓内排序之前。不会自动切换成均分。

## 生效范围

- 新建空箱入库任务选择“自动推荐”时，按规则选空库位。
- 新建物料入库单选择新箱时，按同一规则分配实际在库空箱。
- 批量建单按规则逐条预留，避免重复分配；整批中任一条失败则整批不保存。
- 指定目标库位、人工选择已有物料箱、已有任务和原位返库不受新规则重新排序或改位影响。
- 停用、未核对、占用、预留及双伸通道检查保持生效。前后方向指列号，不代表双伸前后排；同坐标可用空位入库仍优先后排。

分配规则独立保存并持久化，不更改货架范围或核对状态；“总层列数”窗口只保存库位结构。其他终端已更改规则时，旧窗口提示重新打开，避免覆盖他人设置。

## 本机更新

更新包：`release/wms-balanced-allocation-update`。后台代码与网页需要一起更新。

1. 等待正在搬运或交接中的任务完成、清空交接点；待下发任务可保留。更新期间其他终端暂停建单下发。
2. 在后台主机双击根目录 `更新库位设置并重启WMS.cmd`。
3. 出现 `WMS 1.5.0 is running` 后，在电脑按 Ctrl+F5，PDA/平板重新加载页面。
4. 局域网地址仍为 `http://192.168.1.45:8770/`。

更新入口验证包文件校验值、端口所属进程和当前设备/任务状态，备份仓储账本与 PLC 命令记录后切换程序。备份写入 `data/wms/backups/rack-allocation-deploy-*`；不覆盖控制密钥、网络配置、库存、箱号或历史任务。脚本支持 `-CheckOnly`，只做检查，不停止或启动服务。
