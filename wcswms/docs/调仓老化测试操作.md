# 调仓老化测试

入口：左侧“调仓”→“老化测试”。测试在顶部选中的设备内运行，固定使用单伸库位。显示编号为“仓侧-层-列”，例如 R-06-15 表示右仓 6 层 15 列。

## 一圈的八个步骤

| 组别 | 去程 | 回程 |
| --- | --- | --- |
| 1 | L-01-01 → R-06-15 | R-06-15 → L-01-01 |
| 2 | L-01-15 → R-06-01 | R-06-01 → L-01-15 |
| 3 | R-01-01 → L-06-15 | L-06-15 → R-01-01 |
| 4 | R-01-15 → L-06-01 | L-06-01 → R-01-15 |

第四组也执行回程。每次动作必须匹配 PLC 完成状态及任务号、完成回执确认，并恢复空闲后才进入下一步。完成八步才增加一圈。

老化采用独立的坐标任务，不判断 WMS 库位是否有料箱、不要求原位有库存或目标位为空、不要求库位已核对。不会创建测试库存、预留库位或料箱，也不会更新库存位置、物料、数量、批次和库位状态。实际动作仍由 PLC 执行，PLC 的接单条件、报警及现场设备联锁继续生效。

## 准备和启动

1. 确认当前设备货架配置包含全部测试坐标，并启用这些库位。无需在 WMS 登记测试料箱，也无需调整库位占用状态。
2. 清理当前设备的未结束任务，现场核对固定坐标、动作区域和控制权。
3. 设备在线，CPU 为 RUN，无报警，远程任务许可开启，命令及确认信号已复位，并启用自动回执确认。
4. 设置目标圈数：0 为持续循环，大于 0 时完成指定圈数自动结束。单步超时默认 300 秒，可设置 30–3600 秒。
5. 点击“开始老化测试”，核对固定坐标及自动运行范围后勾选确认。启动需要库存调整与设备控制两项权限；只读账号可以查看进度。

启动时再次校验测试坐标及未结束任务。确认过程中坐标、启用状态或任务变化时需重新核对；库存变化不影响老化准备条件。运行期间当前设备独占，禁止其他仓储作业登记、下发、盘点、库位及连接设置变更；其他设备独立运行。

## 随时停止

- **停止循环**：立即禁止下一步下发。没有搬运时直接结束，未下发步骤取消；正在搬运时等待该步完成及回执确认后结束。页面“等待当前步结束”表示尚未结束搬运。
- **请求设备停止**：向 PLC 发出既有软件停止指令，同时暂停老化后续下发。需现场确认停机及执行结果，保留当前任务供核对。软件指令不能代替设备实体急停。

中途停止不会自动发返程。重新启动从第一步开始；请先现场核对设备状态和后续动作范围。WMS 库存位置不会随老化动作变化。

## 暂停、恢复及记录

连接中断、CPU/报警/远程许可变化、任务号不匹配、单步超时、启动账号权限变化或后台重启均暂停后续下发，不自动重发。超时本身不会宣称设备已停止，应核对现场状态，必要时请求设备停止。

当前步骤显示“待现场核对”或“完成回执处理中”时，可点击“处理当前步骤”。按实际执行结果记录起点/目标结果；坐标老化的人工处理也不会更新库存。设备仍处于中间动作时，先现场处置到已知状态再记录。

人工取消或人工纠正结果的步骤不计入老化成功；正常匹配完成回执后人工补确认回执的步骤可以计数。异常处理后不自动继续循环，需结束测试、现场核对，再明确开始新的测试。

升级前已登记的库存关联老化任务继续按原任务类型处理，以保留原有库存及预留的恢复逻辑；结束旧批次后，新启动的测试统一使用坐标模式。

关闭浏览器不会停止后台测试；应使用停止按钮。后台重启后保持暂停，不自动恢复老化。当前批次的完成圈数、完成步数、时间及原因保存在账本，最近 50 个结束批次保存结果；具体搬运记录可在“任务 → 料箱任务 → 全部任务”查看，操作记录包含启动、停止、暂停及结束原因。

沿用实际 WMS 调仓协议 function=3、完成状态 DBW0=3 和既有 DBW32 回执握手。独立请求号、PLC 任务号与持久化意图防止重复下发；任务号不足时暂停，不自动回绕。

开发验证使用隔离账本和 FakePLC，包含完整循环、停止、异常及界面验证，未向现场 PLC 下发老化测试。
