# 物料信息导入

入口：**库存 → 物料档案 → 下载模板 / 导入物料信息**。

1. 在顶部选择目标仓库和设备；物料档案按设备独立保存。
2. 下载 Excel 模板，填写物料编码、物料名称、型号、规格。编码是唯一标识，必须按文本填写，保留前导零。其他字段可以留空。
3. 选择 `.xlsx` 或 `.csv` 文件进行预览。Excel 读取首个工作表，数据须在首 1001 行、四列以内；不支持公式、宏文件或旧版 `.xls`。CSV 支持 UTF-8 和 GB18030 编码，英文表头 `sku,material_name,model,specification` 也可使用。
4. 查看新增、补全、跳过和错误数量，分页核对记录。点击编码或“需修正”可查看完整字段与错误原因；可勾选“只看错误行”。每次最多 1000 条，文件最大 2 MB。
5. 所有行校验通过后勾选核对，点击“确认导入”。如有重复编码、空编码、超长字段、档案冲突，整批不会导入，请修正文件后重新选择。

导入新增编码、补全已有档案的空字段。非空字段不同会阻止导入，空白单元格不会清除已有信息；相同记录跳过。已有物料的非空信息需要修订时，请在库存详情中编辑并核对。未结束物料单据涉及的档案暂不能补全。

补全信息同步同编码料箱的名称、型号、规格，已有任务保留建单时的资料。导入不改变库存数量、批次、库位、预留或任务状态，也不发送 PLC 指令。没有库存的编码仍可建档，在登记物料入库时扫描编码可自动带出资料。

所有登录用户可查询档案、下载模板。导入及预览需要“库存调整与物料维护”权限，管理员默认具备，操作员默认不具备。管理员在“设置 → 用户管理”授权。

更新已有部署时停止后台后更新源码与 `web/dist/`，在项目目录执行 `.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt`，再启动 WMS 并按 Ctrl+F5 刷新浏览器。新部署的安装脚本会自动安装 Excel 读取依赖。保持原 `data/` 和本机配置。
