# 真机只读三维展示

本机启动 `启动真机只读三维.cmd`（与 `启动真机只读.cmd` 共用同一后台，不要重复启动）。安卓平板接入公司局域网后，在浏览器访问 **http://192.168.1.45:8765/**。后台读取有线 PLC `192.168.0.100:102`，平板不需要访问 PLC 网段，也不需要控制密钥。变量与采样记录入口为 `/monitor`。

`config/plc.json` 保持 `profile=PHYSICAL_READONLY`、`control_enabled=false`、`web_view=twin`、`axis_feedback=DB5_CURRENT_POSITION`。只读启动器检查配置；后台不创建控制器，所有 POST/PUT/PATCH/DELETE 接口返回 403。读取不包含任务确认、心跳、复位或任何 PLC 写入。

采集 CPU 状态、DB2.DBW0/2/4/6 和 DB5.DBD22/26/30，每轮约 1 秒；通信中断、坐标读取失败或数据超过 5 秒未更新时标记过期，保留最后数值和模型位置。网页使用持久化的现场显示基准，后台重启后不会改变对齐位置。

| 坐标 | 来源 | 类型 / 单位 |
| --- | --- | --- |
| 行走 | HMI不保持.行走当前坐标 / DB5.DBD22 | REAL / mm |
| 升降 | HMI不保持.升降当前坐标 / DB5.DBD26 | REAL / mm |
| 货叉 | HMI不保持.货叉当前坐标 / DB5.DBD30 | REAL / mm |

地址根据资料包 `data/siemens/exports/20260922-110939/plc-1-PLC_2-block-7-HMI不保持.xml` 的标准 DB5 成员顺序与字对齐推导；`plc-1-PLC_2-block-24-轴控制.xml` 网络 1 将各工艺对象 `ActualPosition` 转换为 REAL 后写入这些变量。三个轴参数导出均为 `_Units.LengthUnit=1013`；[Siemens 工艺对象单位文档](https://docs.tia.siemens.cloud/r/en-us/v20/using-s7-1500/s7-1500t-synchronous-operation-functions-s7-1500-s7-1500t/tags-of-the-technology-object-data-blocks-s7-1500-s7-1500t/tags-of-the-synchronous-axis-technology-object-s7-1500-s7-1500t/units-tag-synchronous-axis-s7-1500-s7-1500t) 将 1013 定义为 mm。现场程序若变更，应重新核对这些地址和单位。

2026-09-23 现场已确认单点基准：**一层一列 = 行走 871、升降 -28、货叉 0 mm**，且行走方向与原显示相反，货叉当前处于中间位置。独立配置 `assets/structure/physical-calibration.json` 是现场显示标定源，网页刷新时读取；不需要修改 PLC 或重启后台，CAD 重建也不覆盖此文件。

映射公式：`CAD_X = 10.236742 - (PLC_X - 871) / 1000`、`CAD_Y = 5.259672 + (PLC_Y + 28) / 1000`、`货叉伸出量 = PLC_Z / 1000`。物理第一列从 CAD X 最大端起编号；第一层使用 CAD 最低料箱底面。中级/末级叉分别扣除 CAD 原装配的 0.34 / 0.68 m 伸出偏移，使 0 mm 显示为居中收回，再暂按 1:2 联动。

这是**单点对齐**，行走方向和货叉零位已根据用户反馈修正。升降/货叉正方向、双级联动比例、实际层列间距和其他位置仍待多点核对，不能据此判断间隙或碰撞。没有真实库存数据，不加载演示库存；“图纸料箱”仅为设计占位。旧 API 的 `twin.relative_m` 字段保留用于兼容，当前网页使用 `axes` 原始值与固定显示配置，不使用启动时相对基准。

首次下载完整模型约 66 MB；平板默认隐藏五金并使用较低像素密度。单指旋转，双指缩放；“设备局部”和“全景”只改变视角。数据来自真实 PLC，设备动作需由现有现场系统操作，本页面不提供控制。

若公司网段 IP 更改，更新 `listen_host` 后重启。若本机可访问而平板无法打开，核对平板是否能访问 `192.168.1.45`、Wi-Fi 是否开启客户端隔离，以及后台主机入站 TCP 8765 防火墙规则。
