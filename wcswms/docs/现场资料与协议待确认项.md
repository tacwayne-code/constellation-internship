## 首批必须澄清的协议问题

| 优先级 | 未确认项 | 对实现的影响 / 建议 |
| --- | --- | --- |
| P0 | DBW6 的枚举、发送/接收/确认时序、各字段写入方 | 没有确认语义时，WCS 不能把 TCP 写成功当作 PLC 接单 |
| P0 | 启动为边沿还是电平；何时清零；完成位如何清除 | 防止重复启动、丢指令和误读旧完成状态 |
| P0 | DBW2 只回传完成任务，是否能查询当前已接受/运行任务 ID | “PLC 已接单但 WCS 掉线”时必须能恢复；若无法确认，进入人工核对，禁止盲目重发 |
| P0 | 任务 ID INT 的有效范围、0 的含义、重启保持和重复 ID 处理 | WCS 内用 UUID，映射 PLC 短序号；在实际范围确认后处理回绕和历史回执，不能只按数值相等认定新任务完成 |
| P0 | DB2 是否允许绝对地址访问；PUT/GET、访问保护、固件与网络参数 | 决定 S7 驱动是否可用；不能擅自更改 PLC 保护设置 |
| P0 | HMI 与 WCS 的控制权、自动许可、设备重启后的动作行为 | 同一设备单写入者；模式改变和重连后先核对再调度 |
| P0 | 站台有货/空位、准备/允许交接、交接完成与载荷标识 | 完成一次设备动作不一定等于整笔业务交接完成 |
| P0 | 故障、停止、急停后货叉和物料所在位置，恢复/复位协议 | 已取货的任务不能简单取消并释放库存；需要独立恢复流程 |
| P1 | 当前行走/升降/货叉位置、速度、原点、载荷检测、限位、手自动与心跳 | 当前交互表未提供连续轴位置，不能承诺真实连续 3D 映射 |
| P1 | 层列坐标、左右方向、深位遮挡、货物尺寸和重量约束 | 决定上架策略、运动映射和双深位调仓 |
| P1 | 报警复位指令与可恢复分类 | 有复位完成状态，但表中未给出对应命令，不能自造码值 |

建议补充独立遥测区，字段由电气工程师结合现有程序确认；包括轴位置和量纲、载荷存在、模式、心跳、当前任务 ID、接单确认与程序启动序号。新增字段不会在未核对 DB 布局时写入现有偏移。

## 真机边界

WCS 负责搬运任务和许可判断；轴运动、限位、急停与安全联锁由 PLC 和现场安全回路负责。表内“命令码 3：急停”只能视为协议中的软件命令，不能据此认定具备安全急停功能。真机测试先只读、再由现场人员配合空载单步、最后带载验收。
