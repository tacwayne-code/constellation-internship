# 物料单据：取箱、人工操作、返库

版本：WMS 1.8.0。本机入口：http://127.0.0.1:8770/ ，局域网电脑使用后台主机的当前 IPv4 地址与端口 8770。扫码枪采用 USB / 蓝牙键盘输入，扫描后回车。

2026-10-16 更新支持同箱多种物料，并修复清单栏遮挡“加入单据清单”按钮。程序更新后需启动新版后台，并用 Ctrl+F5 刷新网页。

## 扫码输入法

电脑扫码前，在 WMS 输入框内将输入法切到英文（英 / EN）。现场确认同一码 `WHSTOCKF5BZD0203` 在中文输入状态丢失末尾 `0203`，切换英文后完整；该码长度为 16 位。记事本与浏览器可能处于不同输入法状态，请在 WMS 内切换。

2026-09-28 16:46 网页已增加英文输入提示与已接收位数，Ctrl+F5 刷新即可，无需重启后台。另修复物料配箱弹窗在扫码中途抢焦点的问题：后台查询仍自动进行，配箱弹窗在回车、Tab 或离开编码框后出现。桌面、手机和完整物料单据流程已通过隔离验证，生产网页仅做扫码读取检查。

## 入库

1. 在“入库 → 物料入库单”扫描或输入物料编码。
2. 新编码填写名称、型号、规格；系统从实际在库空箱中自动分配，不需输入箱号。
3. 已有编码自动带出档案。有空箱时默认系统分配空箱，可直接加入清单；需要同箱混放时，点击“选择料箱 / 多物料同箱”，选择一个在库空箱或已有物料箱。新编码也可选择已有箱。同编码追加沿用该物料原批次；同编码不同批次仍需另一箱。
4. 填写本次入库数量，点击“加入单据清单”，看到下方清单条数增加后继续填写下一条。多种物料放同箱时，每条均选择同一箱号，最后“提交 N 条”。同箱多条合并为一张单据，一次取箱、一次返库；“系统分配空箱”的各条默认分别配箱。每批最多 50 条物料。
5. 在待办单据点击“核对取箱”，现场核对后下发。分配的空箱或已有物料箱会从原库位送至码头 1。
6. 页面变成“待人工装料”后，按本单数量装料，点击“装料完成，返库”，核对并下发返库。
7. 料箱回到原库位、PLC 完成回执匹配后，各物料分别增加本单数量，其他物料保持不变。正常回执自动确认，单据完成。每箱最多 50 种物料，总数量不超过 1000000。

## 出库

1. 在“出库 → 物料出库单”输入条码、物料编码、名称、型号或规格，按“箱号 + 物料”选择库存。同箱多物料会分别列出，扫描箱号后需明确选择本次物料。
2. 填写本次取料数量，不得超过箱内该物料库存。可以创建单条或提交多条；同箱不同物料在一批提交时合并取箱。
3. 点击“核对取箱”并下发，等待料箱到达码头 1，页面显示“待核对取料”。
4. 点击“核对取料并返库”，按当前设备的扫码设置扫描实际箱号和本单每种物料编码。默认两项必扫，多物料需逐项匹配；扫码回车不会直接触发返库。
5. 按单据取出物料，确认料箱已就位，点击“确认并下发返库”。
6. 返库完成后，仅扣减本单指定物料。某物料取完时保留其他物料；全箱全部物料取完后才转为空箱，保留原箱号及长期物料档案。

## 排队与异常

- 单据创建时同时预留料箱和原库位。取箱、人工操作、返库期间，该原库位不能被分配、停用或解除占用。
- 固定交接点一次处理一箱；该箱返库前，其他单据保持待办。单据不会自动开始下一箱搬运，操作员逐条核对下发。
- 同一箱有未完成单据时不能再次建单，请合并本单数量、选另一箱，或待该箱返库完成后再登记。
- 没有可用在库空箱时，可明确选择一个可用已有箱混放；需要新空箱时，在“库存”盘点登记真实空箱，或通过“空箱入库”完成入库。系统不会虚构箱号或空箱。
- 单据数量仅在匹配的返库完成回执（或已核实到位的异常人工处理）时过账。取箱到站、勾选确认、点击返库都不会提前增减库存。重复请求、重复采样不会再次扣增。
- 取箱尚未下发可取消并释放预留。返库下发前取消，仅取消本次返库搬运，保留单据、站内料箱和原库位；之前已完成的装料或取料不要重复做。
- 通信异常造成下发结果不确定时，保留预留并显示“待现场核对”，不自动重发。正常完成回执自动确认；回执确认失败时显示异常原因，由操作员现场核对后重试。
- 后台重启后，“待人工装料 / 待核对取料”继续保留。尚未确认完成的搬运进入核对流程；核对到匹配回执后继续对应步骤。

## 空箱与 PLC 对接

“库存 → 物料库存”按编码汇总，各物料详情显示同一箱中该物料的数量；料箱详情和库位详情列出箱内全部物料并分页。库存导出每种箱内物料独占一行。同箱调仓移动整箱，保留全部物料和数量。旧单物料库存及未完成旧单据可继续使用。

入库、出库页保留独立“空箱入库 / 空箱出库”入口，使用每箱独立条码，沿用原先的直接空箱搬运和出口扫码交接流程。

库位单双伸只在库位管理设置，物料出入库按实际料箱原库位带入。编号显示统一为仓侧、层、列，不显示伸位后缀，伸位另行标注。

每张物料单据包含一次出库取箱与一次入库返箱。PLC 接口不新增功能码：取箱 function=1、源地址为原库位、目标四个 0；返库 function=2、源地址四个 0、目标为原库位。码头保持 1；参数写 DB2 字节 8–27、任务号 DBW30、启动 DBW28，完成确认沿用 DBW32。每次搬运分配独立 PLC 任务号。

## 验证与部署

隔离数据库与 FakePLC 验证了批量配箱、追加同箱物料、部分出库、取空转为空箱、原库位预留、扫码不符拒绝、重复请求、断线、重启和异常核对。Edge 页面验证覆盖桌面、平板、手机，完整操作过程中无脚本错误。实际机械搬运仍由现场操作员按新流程进行首单验收。

## 出库扫码设置

管理员在“设置 → 出库扫码”分别设置“箱子编码需要扫码”和“物料编码需要扫码”。默认全部开启，可以只扫其中一项，也可以都关闭。设置对应顶部选中的设备，独立保存至该设备的账本，重启后保留。保存后对尚未提交返库的物料出库单立即生效；已提交的返库步骤不重复创建。

关闭某项后，取料核对窗口隐藏对应输入框。操作员仍须确认按单据数量取料、料箱已就位，设备满足接单条件后才能返库。后台按保存的要求校验必扫项；设置并发变化时需重新核对。设置修改记录进入操作记录，单据人工确认中保存当时采用的扫码要求。此设置适用于物料出库单，空箱出库的提走交接流程保持原有要求。
