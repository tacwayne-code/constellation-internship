# 整箱调仓

同一设备内整箱从原库位搬到目标空库位，支持物料箱及空箱。顶部选中的仓库和设备决定账本，不会跨设备搬运或跨仓库调拨。

## 操作步骤

1. 进入左侧“调仓”，按箱号、物料编码、名称、型号、规格或库位搜索并选择料箱。
2. 选择目标空位，可按编号、层、列及单伸/双伸筛选。候选分页显示，无需下拉。
3. 核对两端库位、箱号和数量，点击“登记调仓任务”并勾选确认。登记仅保存任务，同时预留原位、目标位和箱，没有下发动作。
4. 在“待办调仓”点击“核对并下发”，核对库位、料箱、动作区域及现场控制权后下发。设备必须在线、空闲、无报警、允许接单，且无未结束搬运回执及交接点料箱。
5. 调仓完成状态及任务号匹配后，库存位置改为目标位，两端预留释放；物料、批次、数量、箱号和入库时间保持不变。正常回执自动确认后任务结束。

历史记录在“任务 → 料箱任务 → 全部任务”查看，详情显示原位与目标位。库位页显示两端任务预留，登记和任务操作进入操作记录。

## 选位及权限

- 源箱须在库、未预留且没有未结束任务，两端库位须已建档、启用并核对；目标须为空、未预留且不同于原位。
- 登记和下发均重新校验库存及双伸通道。双伸前排不能被其他箱或任务阻挡。同一层列前后排调仓按“先取出本箱，再放到目标”校验，不把本次调仓自身预留视为其他任务。
- 登记和取消需要“库存调整、调仓与物料维护”权限，下发、回执和异常处理还需要“任务下发与设备控制”权限。默认管理员具备权限，其他用户由管理员分配。

## 取消与异常

仅待下发任务可取消，取消后释放两端库位和箱的预留，原库存位置及数量保持不变。

下发不确定、报警或后台在运行中重启时保留预留并进入现场核对，不自动重发。确认箱仍在起点时取消调仓并保留原库存；已到目标时按现场结果更新目标位置。核对结果需记录说明。

箱仍在货叉或中间位置时，先现场处置到已知原位或目标位再记录结果，不应通过盘点或解除占用绕过未结束调仓。

## PLC 协议及验证范围

使用项目已有 function=3，源和目标四个坐标均明确填写，码头沿用当前设备的出库码头配置。参数写 DB2 字节 8–27，独立任务号写 DBW30，启动最后写 DBW28。完成状态为 DBW0=3，反馈及命令任务号须匹配；完成确认沿用 DBW32。

功能及完成状态依据《现场资料与协议待确认项》和原 PLC 程序导出。开发验证使用隔离账本、FakePLC 和界面测试，未向现场 PLC 下发调仓。现场运行应核对真实库位及实际动作结果。
