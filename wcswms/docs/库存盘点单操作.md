# 库存盘点单

盘点按当前设备内的整箱执行。创建单据后取箱出库，在交接点核对实际物料、数量和批次，再确认返库；只有返库完成回执匹配后才更新库存。单据编号为 `PD-`。

## 操作步骤

1. 选择顶部仓库、设备，在左侧“库存管理 → 盘点单”进入；库存查询工具栏的“盘点单”也可进入。
2. 搜索并选择一个可用在库料箱，填写盘点说明，点击“创建盘点单”。空箱和多物料箱均支持。创建只预留料箱及原库位，不下发 PLC、不改数量。
3. 在进行中的盘点单点击“核对取箱”，核对箱号、原库位及现场控制权后下发。设备将整箱取出到原出库交接点，原库位继续保留。
4. 取箱回执确认后进入“待盘点核对”。点击“核对盘点并返库”，逐项填写实盘数量、批次；通过“添加物料”补记箱内实际存在的物料。
5. 填写核对说明及差异原因，勾选确认后点击“确认盘点并下发返库”。设备返回原库位；完成回执匹配后统一按实盘结果记账，记录每种物料的盘盈或盘亏，单据完成。

实盘数量是最终绝对数量。例如账面 10、实盘 7，返库后记为 7，并记录差异 -3。填写 0 或移除原物料行表示该物料实际不存在；全部物料为 0 时转为空箱，保留箱号。每箱最多 50 种物料，总数量不超过 1000000。同一物料编码不能重复。

已有编码使用物料档案中的名称、型号及规格；盘点不修订既有档案。新编码可填写资料并随本次确认登记。多条明细通过页码核对，不会拆成多个取箱任务。

## 查询、权限与恢复

- 盘点页“进行中 / 全部盘点”查看当前及历史单据；任务页增加“待盘点”，全部任务可查看盘点及取箱返库进度。
- 任务列表点击整行即可切换详情，详情中的物料翻页固定在底部。
- 建单、取消需“库存调整、盘点、调仓与物料维护”权限；下发、核对返库及异常处理还需“任务下发与设备控制”权限，且设备连接已启用。
- 操作人员取自登录账号，记录建单及后续操作；自动回执不会替换人工操作者。历史记录未保存人员的显示“历史未记录”。
- 重复提交同一请求不重复建单或重复写入搬运命令。原库位与箱内账面快照变更、库位停用或通道受阻时禁止继续。
- 仅未下发的步骤可取消。取消取箱会结束盘点并释放预留；取消返库则保留交接点料箱、原库位及核对记录，可重新核对实盘信息后返库。
- 执行中断或服务重启后不自动重发。结果不确定时保留预留，在“现场核对处理”中依据实际位置恢复；不能把“已发送”当作搬运完成。

库存页的“登记已有库存”用于初始登记现场已存在、尚未建账的箱子，不执行搬运；日常实物盘点使用上述盘点单流程。

## 列表与库位显示

物料库存、物料档案每页 10 条，最后一页显示剩余条目，筛选后回到第一页；长资料可打开详情查看。库存表的账面数量只显示物料数量，箱数及预留箱数在详情内查看。库位图、列表及详情统一使用：有料箱蓝色、空箱青绿色、任务预留紫色、可用空位浅绿色；预留、停用等状态优先显示。
