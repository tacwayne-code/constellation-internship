WCS 真机 PLC 调试套件 — Windows 10/11 x64

一、安装到另一台主机
1. 将整个 ZIP 复制到目标主机，右键“全部解压”。不要直接在压缩包中运行。
2. 双击“一键安装.cmd”（或 Install.cmd）。
3. 选择目标主机实际的公司局域网 IP，例如 192.168.1.x。
   PLC 地址默认 192.168.0.100，S7 端口 102，机架 0，槽号 1；网页端口默认 8765。
4. 首次迁移到同一台 PLC 时，建议继承任务记录：先退出旧后台，再复制旧主机
   data\physical-commands.sqlite3，安装时选择该文件，保留已用任务号和不确定写入记录。
   不要仅复制仍在运行的 SQLite 主文件；如有 -wal/-shm 文件，请先正常退出旧后台。
5. 点击“安装”。运行环境已包含在包内，安装不需要下载 Python、Node、TIA 或依赖。
   如勾选允许局域网访问，会请求管理员授权添加仅针对该程序、公司网卡和公司子网的规则。
   不关闭防火墙、不修改网卡地址、不搭建网桥、不启动软 PLC，不自动启动后台。

二、启动和访问
1. 先退出旧主机正在运行的调试后台，确保同一 PLC 只有预期的控制方。
2. 在新主机双击桌面“WCS 真机调试后台”或安装目录 StartBackend.cmd（启动后台.cmd）。
   控制台应持续保持打开；Ctrl+C 停止后台。软件不会自行下发任务。
3. 双击 OpenConsole.cmd（打开调试台.cmd），或者在其他电脑打开：
   http://新主机公司局域网IP:8765/
4. 首次启动会生成独立控制密钥，位于安装目录 data\physical-control-key.txt。
   将文件内容复制到各调试浏览器的控制密钥输入框，先点击“检查控制连接（不下发动作）”。
   密钥不会沿用旧主机的密钥；同一目录升级则保留已有密钥。
5. 需要手动补设防火墙时双击 AllowLan.cmd（允许局域网访问.cmd）；取消管理员授权不会影响安装，
   但其他电脑可能无法访问。失败原因保存在 firewall-setup-error.txt。

三、网络准备
后台主机需要能够同时访问 PLC 网段和公司局域网。
示例：有线网卡 192.168.0.x/24 → PLC 192.168.0.100；公司网卡 192.168.1.x → 浏览器电脑。
不要将旧主机的 192.168.1.45 直接配置给新主机，选择新主机自己的空闲/已分配地址。
网卡地址和路由由现场按实际网络设置；本安装器只选择网页绑定地址。
如果以后公司 IP 改变，停止后台，修改安装目录 config\plc.json 的 listen_host，
重新运行 AllowLan.cmd，然后启动后台。

四、当前功能
真机 DB2 实时反馈、任务下发、停止命令、请求与任务号去重、写入后参数读回、控制密钥验证。
移动任务的码头、取箱和放箱字段可为 0；入库取箱/出库放箱字段也支持 0。
其他任务继续使用原有参数约束。SENT 代表 S7 写入返回，动作结果以设备反馈为准。
这份包是当前真机调试台，不包含 Siemens 授权软件、TIA 工程编辑器、软 PLC、CAD 原始资料、
旧主机密钥或实际任务记录。TIA 编程、下载 PLC 程序需要另外准备 Siemens 环境。
自动任务完成确认、库存联动及无人值守调度不在本包的已验收范围内。

五、升级、排错与移除
再次运行安装器并选择已有安装目录：保留 config、data（包括密钥与任务记录）。
升级前先退出后台；旧安装目录会保留为同级 .backup-日期-随机编号，确认正常后自行清理。
CheckEnvironment.cmd（环境自检.cmd）检查运行库与绑定地址，不连接 PLC。
端口被占用、公司 IP 不在本机时，启动会报错，不会改绑到其他网卡。
移除前先退出后台；保留需要的 data 目录后删除安装目录与桌面快捷方式即可。
如创建了防火墙规则，可在 Windows Defender 防火墙高级设置中删除本套件对应的入站规则。

六、构建与验证
安装包附 SHA-256 文件和逐文件清单；安装前自动校验 payload 文件。
使用 PyInstaller 自包含打包，运行库定位按官方文档：
https://pyinstaller.org/en/stable/runtime-information.html
第三方许可证位于安装目录 licenses；本套件相关源码位于 source。
snap7 对应的 Python 源码与许可证位于 third-party-source，便于审阅和替换重建。
构建脚本为源工程 scripts/package-windows.py；应在 Windows x64 与锁定依赖环境中运行。
本包未经商业代码签名；按贵司软件准入流程核对哈希后使用，不要求关闭安全软件。
