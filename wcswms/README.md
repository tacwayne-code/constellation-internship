# WCS / WMS 仓储作业系统

当前常规 WMS 版本 **1.8.0**。后端为 Python / FastAPI / SQLite，前端为 React，后台通过 S7 TCP 与 PLC 通信。电脑、安卓平板和 PDA 用浏览器访问同一后台。

**新电脑部署先看 [局域网部署步骤](DEPLOY-LAN.md)。** 已包含当前前端构建产物，使用常规 WMS 不需要安装 Node.js、TIA Portal 或 PLCSIM。Windows 10/11 x64、Python 3.12 x64、可联网安装 Python 依赖即可。

**2026-10-13 物料导入更新：** “库存 → 物料档案”支持下载 Excel 模板、XLSX / CSV 预览与批量导入，最多 1000 条 / 2 MB。仅新增编码或补全空字段，相同记录跳过，冲突与错误会阻止整批导入；资料按当前设备保存。还修复了矮窗口待办按钮与分页重叠。旧部署更新后需安装新的 `requirements.lock.txt` 依赖并重启后台、强制刷新浏览器，保留原数据和配置。详见 [物料导入操作](docs/物料信息导入操作.md)。

**2026-10-12 用户与设备更新：** 增加用户登录、用户与权限管理、操作记录、多仓库与多设备。管理员在“设置 → 仓库设备”创建仓库和设备，在顶部切换操作范围。每台设备独立管理货架、库位、库存、任务和单据，新设备使用空账本并默认停用连接；原账本保留为默认仓库的主设备。已有用户与库存继续保留，新安装自行创建管理员，软件没有默认密码。

**2026-10-08 操作界面更新：** 深石墨与青绿配色，登记、待办与 PLC 状态同屏；库存、任务、记录与库位视图按窗口分页，主要操作无需下拉。新建单据清单以摘要与弹窗呈现，窄屏通过切换查看完整内容。更新后请强制刷新网页。启动前可运行 `WMS环境自检.cmd`；详见 [进度与操作记录](docs/常规WMS部署与操作.md)。

## 当前功能

- 扫码/触屏操作，物料编码长期建档，保存名称、型号、规格；创建入库单按编码、名称、型号或规格模糊查找并选择候选物料，支持键盘与扫码确认。
- 物料库存按编码汇总账面数量，空箱不计入；点击详情查看对应料箱、库位及作业状态。
- 物料档案搜索、详情、Excel 模板、XLSX / CSV 批量导入与逐行校验；需要库存维护权限，不改变库存数量或发送 PLC 指令。
- 多条入出库单据，自动配空箱或选择已有物料箱，取箱、人工装料/取料、返库后按单过账。
- 独立空箱条码；取料后数量归零自动转为空箱，保留箱号。
- 库位平面图、总层列数、单双伸、停用/启用、解除占用与双伸通道检查。
- 库位状态使用明显区分的颜色：已占用蓝色、任务预留紫色、可用空位绿色、通道待清空橙色、待核对黄色、停用灰色、未建档浅灰。平面图、图例、列表与详情统一，悬停保留状态色。
- 先左后右、先右后左整仓优先，左右交替均分；上下、列号正反顺序可随时设置。
- 待下发取消、人工核对下发、正常完成自动关联回执、异常核对和重启恢复。
- 用户登录、管理员/操作员/只读/自定义角色，按入库、出库、库存、库位、设备控制和连接设置分别授权；设置中维护用户与操作记录。
- 多仓库、多设备登记与切换，各设备拥有独立账本和 PLC 参数；同一 PLC 地址和端口不能重复绑定。
- 设备页保存 PLC IP 并重连；操作按用户权限验证；设备有未结束任务或交接未完时不能启停或修改连接参数。

后台已包含 WCS 通信与任务处理，**常规 WMS 只启动 `启动仓储WMS.cmd`，无需额外启动另一套 WCS**。PLC 仍负责运动、联锁和状态转换。

## 三个独立入口

1. **常规 WMS 真机读写**：`启动仓储WMS.cmd`，默认端口 8770；任务由操作员核对下发，匹配的正常回执自动处理。
2. **本机仿真**：`启动仿真MVP.cmd`，`http://127.0.0.1:8766/`；使用独立模拟 PLC 与 `data/simulation/`，含演示库存，不连接真机。
3. **真机只读三维**：`启动真机只读三维.cmd`，公司局域网地址的 8765 端口；独立只读入口，现场零点/方向需按设备标定。

## 开发与测试

依赖安装及配置初始化后：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

重新编译网页时才需要 Node.js 与 pnpm，前端使用 `web/pnpm-lock.yaml` 锁定依赖：

```powershell
cd web
pnpm install --frozen-lockfile
pnpm build
```

已验证常规 WMS 的任务、库存、物料单据、自动回执、库位规则、用户权限和多设备数据隔离，并通过电脑/平板/手机界面测试。隔离测试不连接实际 PLC，模拟验证不替代现场机械验收。

## 数据和工程资料

本次发布不包含当前现场库存、账号数据库、密码、控制密钥、日志、网卡修复文件、Python 虚拟环境、软件安装包、原始电气/HMI/TIA 工程或 SolidWorks 原始工程。新的安装从空账本开始；如需接续原仓库，请按部署文档私下迁移完整运行数据，不能把空账本当作原仓库库存。生产数据和本机配置均被 `.gitignore` 排除。`migrations/` 中已有的历史迁移归档保持原样，本次未增加或更新库存快照。

导出的三维资源随软件保留；`scripts/siemens/` 为可选工程辅助工具，使用时须自行提供工程资料和 Siemens 环境。常规 WMS 部署不依赖这些工具。

操作参考：[物料取箱与返库](docs/物料单据取箱返库操作.md)、[库位与分配规则](docs/库位结构与自动分配规则.md)、[详细操作和历史变更](docs/常规WMS部署与操作.md)。历史文档中的本机地址、更新记录仅供追溯；新部署以 [DEPLOY-LAN.md](DEPLOY-LAN.md) 为准。

### 出库扫码设置

管理员可在“设置 → 出库扫码”独立设置箱子编码、物料编码是否必扫。默认两项开启，设置按当前设备持久保存，对尚未提交返库的物料出库单生效。关闭扫码项后仍需人工取料与就位确认。详见 [物料单据取箱返库操作](docs/物料单据取箱返库操作.md)。

### 整箱调仓

左侧“调仓”支持当前设备内物料箱、空箱换库位。选择源箱和目标空位后登记，两端同时预留，核对下发并匹配调仓完成回执后更新位置，数量不变。详见 [整箱调仓操作](docs/整箱调仓操作.md)。

### 调仓老化测试

“调仓 → 老化测试”按四组固定单伸坐标路线往返，八步为一圈。不判断库位有无料箱，不预留或更新 WMS 库存；PLC 接单条件、报警及设备联锁继续生效。支持指定圈数或持续循环、停止后续循环及请求设备停止；运行中设备独占，故障和重启不自动重发。详见 [调仓老化测试操作](docs/调仓老化测试操作.md)。

### 同箱多物料与单据清单

入库逐条“添加物料”，再统一选择一个料箱，点击“创建入库单”，全部物料合并为一张入库单、一次取箱和返库；默认分配空箱也不拆单。已添加物料可修改和移除，各物料独立记账。出库按箱内物料选择与逐项扫码，只扣本单物料，全箱取完才转为空箱。修复清单栏遮挡加入按钮，电脑和手机均可连续加入。详见 [物料单据取箱返库操作](docs/物料单据取箱返库操作.md)。

### 浅色后台与分组导航

界面采用青色用户区、白色分组导航、灰色页签、紧凑工具栏、细线表格和底部分页。导航分为工作中心、库存管理和系统管理，支持分组及侧栏收起；手机保留全部功能入口和退出登录。任务页按待办、待入库、待出库、全部任务筛选，电脑并排显示列表与详情，手机切换查看。物料库存与物料档案每页 10 条；设备页在矮窗口中切换状态和记录，避免遮挡操作。物料合并入库、扫码权限和库位状态色继续沿用现有流程。更新后使用 Ctrl+F5 载入新界面。

### 实物盘点单与操作人员

“库存管理 → 盘点单”支持空箱或多物料箱：创建 PD 单据，核对取箱出库，在交接点填写实际物料、数量、批次及差异原因，确认后返库；仅在匹配返库完成回执后按绝对数量更新库存，逐物料记录差异。支持增补物料、盘空、重复请求防重、取消及重启后的现场核对恢复。建单需库存权限，搬运及确认返库另需控制权限。

物料库存与档案每页 10 条；账面数量只显示物料数量，料箱及预留箱数在详情中查看。库位的有料箱为蓝色、空箱为青绿色、预留为紫色。全部任务新增登录账号来源的操作人员，历史缺失记录不推测补填；点击整行切换详情，详情物料分页固定在底部。单据物料以表格展示编码、名称、型号、规格、批次、数量及账面变动，入库、出库、盘点和核对弹窗同步显示；缺失信息显示“—”。原“盘点登记”更名为“登记已有库存”，用于初始建账。详见 [库存盘点单操作](docs/库存盘点单操作.md)。

### 表单查询、规格核对与选箱明细

工作中心新增“表单查询”：按当前仓库、设备查询出库、入库、盘点及搬运任务，支持日期区间（含结束当天）、今天/近7天/近1月/近3月/全部时间、状态与单据号/箱号/物料/规格/操作人员关键词筛选。读取完整账本，不受作业页最近 200 条限制；结果整行点击查看物料和关联执行记录，底部分页。查询为登录后的只读功能，不下发任务或修改库存。

盘点料箱选项、盘点核对实盘明细显示型号与规格；多物料箱可查看全部箱内明细。入库选箱页面直接以表格展示箱内物料、型号、规格、批次及数量，料箱与物料各自分页，支持按箱内任意物料资料搜索。所有业务页的单伸库位省略“单伸”，仅双伸结构保留前后伸位标识，按当前设备和左右仓分别判断。详见 [部署与操作](docs/常规WMS部署与操作.md)。
