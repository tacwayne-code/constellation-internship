# WCS / WMS 仓储作业系统

当前常规 WMS 版本 **1.6.0**。后端为 Python / FastAPI / SQLite，前端为 React，后台通过 S7 TCP 与 PLC 通信。电脑、安卓平板和 PDA 用浏览器访问同一后台。

**新电脑部署先看 [局域网部署步骤](DEPLOY-LAN.md)。** 已包含当前前端构建产物，使用常规 WMS 不需要安装 Node.js、TIA Portal 或 PLCSIM。Windows 10/11 x64、Python 3.12 x64、可联网安装 Python 依赖即可。

**2026-10-08 操作界面更新：** 深石墨与青绿配色，登记、待办与 PLC 状态同屏；库存、任务、记录与库位视图按窗口分页，主要操作无需下拉。新建单据清单以摘要与弹窗呈现，窄屏通过切换查看完整内容。更新后请强制刷新网页。启动前可运行 `WMS环境自检.cmd`；详见 [进度与操作记录](docs/常规WMS部署与操作.md)。

## 当前功能

- 扫码/触屏操作，物料编码长期建档，保存名称、型号、规格。
- 多条入出库单据，自动配空箱或选择已有物料箱，取箱、人工装料/取料、返库后按单过账。
- 独立空箱条码；取料后数量归零自动转为空箱，保留箱号。
- 库位平面图、总层列数、单双伸、停用/启用、解除占用与双伸通道检查。
- 先左后右、先右后左整仓优先，左右交替均分；上下、列号正反顺序可随时设置。
- 待下发取消、人工核对下发、正常完成自动关联回执、异常核对和重启恢复。
- 设备页保存 PLC IP 并重连；操作需控制密钥；执行中或交接未完不能切换地址。

后台已包含 WCS 通信与任务处理，**常规 WMS 只启动 `启动仓储WMS.cmd`，无需额外启动另一套 WCS**。PLC 仍负责运动、联锁和状态转换。

| 路径 | 内容 |

| `backend/` | 仓储账本、单据、任务、S7 读写与 API |

| `scripts/setup-wms.ps1` | 新主机安装和网络配置初始化 |
| `tests/` | 隔离账本与测试 PLC 的回归测试 |
| `assets/structure/` | 可选三维展示所需的导出模型与映射 |
| `release/wms-device-ip-update/` | 当前完整更新文件，供已有安装使用 |

## 三个独立入口

1. **常规 WMS 真机读写**：`启动仓储WMS.cmd`，默认端口 8770；任务由操作员核对下发，匹配的正常回执自动处理。
2. **本机仿真**：`启动仿真MVP.cmd`，`http://127.0.0.1:8766/`；使用独立模拟 PLC 与 `data/simulation/`，含演示库存，不连接真机。
3. **真机只读三维**：`启动真机只读三维.cmd`，公司局域网地址的 8765 端口；独立只读入口，现场零点/方向需按设备标定。

## 开发与测试

依赖安装及配置初始化后：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

重新编译网页时才需要 Node.js 与 pnpm，前端使用 `web/pnpm-lock.yaml` 锁定依赖：

```powershell
cd web
pnpm install --frozen-lockfile
pnpm build
```

已验证常规 WMS 的任务、库存、物料单据、自动回执、库位规则与 IP 设置，并通过电脑/平板/手机界面测试。模拟验证不替代现场机械验收。

## 数据和工程资料

仓库不含现场库存、任务记录、控制密钥、日志、网卡修复文件、Python 虚拟环境、软件安装包、原始电气/HMI/TIA 工程或 SolidWorks 原始工程。新的安装从空账本开始；如需接续原仓库，请按部署文档迁移运行数据，不能把空账本当作原仓库库存。生产数据和本机配置均被 `.gitignore` 排除。

导出的三维资源随软件保留；`scripts/siemens/` 为可选工程辅助工具，使用时须自行提供工程资料和 Siemens 环境。常规 WMS 部署不依赖这些工具。
