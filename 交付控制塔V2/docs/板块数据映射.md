## 三、Odoo 18 字段注意事项

1. `project.task`：无 `user_id`（用 `user_ids` m2m）、无 `kanban_state`（用 `state`，值 `1_done`/`01_in_progress`）、无 `date_start`（用 `planned_date_begin`）
2. `task.progress` 通常为 0（Odoo 未维护）→ 按 state 推断（完成=100%，进行中=50%）
3. `project.project.date/date_start` 常为 False → 从任务 deadline 聚合
4. `stock.picking`/`purchase.order`/`mrp.production` 标准自带 `project_id` 字段
5. `res.partner` 名称带编号前缀 `[P00xxx]`（历史数据规范）
