# 统一运营看板本地预览

## 最简单的启动方式

双击项目根目录中的 `启动统一看板.cmd`。

首次启动会自动安装前端依赖，完成后浏览器访问：

```text
http://127.0.0.1:5173/
```

保持命令窗口开启即可持续预览；关闭窗口后，本地服务停止。

## 当前演示内容

- 管理层、采购、仓库、现场、生产五套岗位看板
- 每个界面右上角都有“全屏展示”；按 `Esc` 或“退出全屏”返回
- 生产模板额外提供“车间大屏”模式，进入后会隐藏普通顶部栏并放大指标
- 项目、仓库、时间范围筛选
- 指标、趋势、风险、异常、进度和今日重点组件
- 组件显示或隐藏
- 组件顺序调整
- 紧凑或舒适布局
- 个人视图保存在当前浏览器中，刷新后仍然保留
- 一键恢复岗位默认布局

## 数据说明

当前统一看板使用明确标识的演示数据，便于先确认信息结构和操作方式。原项目的 Odoo 后端和业务模块没有被删除；下一阶段可以将统一看板组件逐项替换为真实 Odoo 聚合接口。

## 手动启动

在 `frontend` 目录运行：

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

生产构建验证：

```powershell
npm run build
```
