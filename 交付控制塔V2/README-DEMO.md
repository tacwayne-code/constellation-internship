# 交付控制塔 V2 · 演示部署包

这是一个纯 Web、前端 Mock 数据的多项目交付管理展示版，适合演示生产线、立体仓储、MES/WCS 集成项目的组合管理和全模块框架。

视觉参考：`design-concept-v3.png`。该视觉稿用于展示完整信息架构和风险问题处理中心，实际页面仍由 React/CSS 渲染。

## 直接部署

将 `dist` 目录下的全部文件上传到任意静态 Web 服务器的网站根目录即可。

适用环境：

- Nginx / Apache
- IIS 静态网站
- Vercel / Netlify / Cloudflare Pages
- 内网静态文件服务器

本项目没有后端接口，不需要数据库、Node 服务或环境变量。

## 本地演示

在项目根目录执行：

```bash
npm install
npm run dev
```

浏览器打开：`http://127.0.0.1:5173/`

## 演示建议

1. 从“项目组合驾驶舱”查看 4 个并行项目、组合进度和跨项目阻塞事项。
2. 点击任一项目进入独立项目工作台，再从左侧进入“风险控制”。
3. 在“风险控制”中展示潜在问题预警、阻塞报备、责任人和解除计划。
4. 在项目工作台查看“项目甘特图”，了解计划基线、当前进度和风险状态；点击任务条打开任务详情。
5. 从左侧切换“采购与交期”“物流管理”“现场库存”“人员管理”等模块。
6. 在模块内切换“工作台 / 工作看板 / 记录列表”。
7. 使用“组合周报”和顶部“项目组合 / 搜索”展示产品化交互；移动端可在甘特图区横向查看时间轴。

## 当前版本边界

复杂审批、批量更新、权限、MES/ERP/仓储系统接口均为展示态，不会写入真实业务数据。
