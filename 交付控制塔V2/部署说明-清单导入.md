# 清单导入智能采购功能 — 部署说明

本次在交付塔项目中新增「清单导入 → 自动识别配件 → 推荐供应商 → 批量建采购单 → 回写供应商」完整闭环。

| `services/import_matching.py` | **新增**：名称/规格规范化、类型词+规格提取、产品匹配、供应商推荐、批量建 PO、回写 supplierinfo |
| `routers/list_import.py` | **新增**：5 个接口（upload / parse / match / recommend / create-po） |

## 二、部署步骤

1. **后端**：将 `backend/app/` 下改动文件覆盖到服务器对应目录，安装新依赖，重启 uvicorn：
   ```bash
   cd backend
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
2. **前端**：将 `frontend/dist/` 覆盖到服务器 `frontend/dist/`（或在服务器执行 `npm run build`）。

> 注意：服务器上 vite build 若报 safe-delete 错误，先手动删除 `frontend/dist` 再重试。

## 三、新增接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/procurement/list/upload` | POST | 上传 .xlsx/.csv 文件，自动解析出行（名称 + 数量，支持 48+3 求和） |
| `/api/procurement/list/parse` | POST | 粘贴文本解析出行（名称 + 数量） |
| `/api/procurement/list/match` | POST | 识别配件（name + spec_info 双维度匹配） |
| `/api/procurement/list/recommend` | POST | 推荐供应商（supplierinfo + 历史 + 等级评分） |
| `/api/procurement/list/create-po` | POST | 按供应商聚合批量建 PO（priority=1 + 交期 + 回写） |

## 四、匹配逻辑说明

- 产品匹配：**类型词（name）+ 规格（spec_info）** 双维度精确匹配，如「平垫圈16×3」→ 名称「平垫圈」+ 规格「16*3」→ `P02658`。
- 命中分级：`auto`（自动命中）/ `choose`（候选待选）/ `create`（Odoo 无此物料，需新建）。
- 供应商推荐：supplierinfo 首选 + 历史采购频次 + supplier_rank 评分，加权排序。
- 建单三要素：`priority=1`（紧急）+ `date_planned`（今天+交期）+ `partner_id`（推荐供应商），落库后紧急采购看板自动显示。

## 五、验证结果（2026-08-17 实测）

- RGV 天地轨 38 行外购件 xlsx 上传解析成功：数量「48+3」→51 求和正确，分类行自动跳过。
- 匹配：**25 自动命中 + 7 候选 + 6 需新建**（38 行含天轨/地轨重复物料）。
- 标准件（垫圈/螺母/常规螺钉）全部精确命中；化学螺栓、拉爆螺母、滑触线夹等 Odoo 确无的物料正确标记「需新建」。
- 推荐：25 个自动命中产品中 21 个自动带出供应商。
- 测试创建采购单 `P00396`：priority=1、state=draft、供应商自动带出、交期=今天+1、origin=清单导入，三要素全部正确。
