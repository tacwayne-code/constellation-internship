紧急采购看板 — 使用说明

📊 这是什么

一个只读驾驶舱，连接 Odoo ERP，只展示标有「紧急」且尚未转为采购订单（未采购）的采购单 / 询价单，并按采购清单（Odoo 采购单的「来源单据」字段）分组：先看清单，点进清单再看该清单下的各张采购单。不会写回 Odoo，不会新增、修改、删除任何数据。

🎨 紧急等级（颜色）

P0 亮红预计日期已超期或今天到期，今天必须处理
P1 橙色3 天内到期，尽快确认转采购
P2 黄色4 ~ 7 天内到期，本周关注
P3 蓝色其余紧急未采购单，普通提醒

判定规则：超期天数 > 0 或距预计 = 0 天 → P0；≤ 3 → P1；≤ 7 → P2；其余 → P3

区域内容

📋 数据来源与判定方式

项目说明
紧急标记 读取 Odoo purchase.order 上的紧急字段，按顺序探测： x_studio_urgent / x_urgent / urgent / x_studio_is_urgent / x_studio_priority / priority。
  • 布尔字段：值 = true
  • 选择字段（如 Odoo 18 的 priority）：按选项 label 匹配「紧急 / urgent」，取对应 key
  • 文本字段：按「包含『紧急 / urgent』」匹配
  • 兜底：都未命中则按「单号包含『紧急』」识别
未采购状态默认 ["draft","sent","to approve"]，可在 .env 中通过 ODOO_URGENT_STATES 自定义
预计日期读取 Odoo date_planned；超期天数 = 今天 − 预计日期（负数表示已超期）
等待天数今天 − 下单日期 date_order
金额读取 amount_total（多币种时按 Odoo 主币种显示）
采购员读取 user_id（Odoo 负责的下单人）

⚙️ 配置与凭证

Odoo 凭证写在项目根目录 .env 文件中（不要提交到代码库）。可配置字段与 .env / server.py / README.md 完全一致：

环境变量说明
ODOO_URLOdoo 服务地址
ODOO_DBOdoo 数据库名
ODOO_USEROdoo 登录账号；必须设置才能连接 Odoo
ODOO_PASSWORDOdoo 登录密码；必须设置才能连接 Odoo
ODOO_URGENT_FIELD指定紧急字段名；留空走自动探测，按 x_studio_urgent / x_urgent / urgent / x_studio_is_urgent / x_studio_priority / priority 顺序命中
ODOO_URGENT_TAG紧急标签文本（紧急字段为文本/选择型时按此匹配）
ODOO_URGENT_DOMAIN完整紧急过滤域 JSON；设置后覆盖自动探测
ODOO_URGENT_STATES未采购状态 JSON 数组
PORT服务端口
HOST监听地址；默认仅本机 127.0.0.1，局域网共享改为 0.0.0.0
BOARD_ACCESS_TOKEN可选访问令牌；设置后 /api/* 需携带 ?token= 或 Authorization: Bearer
CACHE_TTL_SECONDSOdoo 数据缓存秒数

编辑 .env 后重启 启动.bat 生效。已设置的系统环境变量优先，不会被 .env 覆盖。各字段的兜底默认值见 server.py 顶部 os.getenv(...) 调用。服务默认仅本机可访问；需局域网共享时设 HOST=0.0.0.0 并建议启用 BOARD_ACCESS_TOKEN。

🔄 数据刷新与缓存

  • 页面每 3 分钟自动刷新，无需手动操作
  • 点「刷新」按钮立即拉取最新数据
  • Odoo 不可达时，看板自动回退本地缓存，状态条会标注「本地缓存」
  • 本地缓存为空时，使用示例数据用于页面预览
  • Odoo 中取消紧急标记或转为采购订单后，最多 3 分钟看板自动更新

🔍 搜索与筛选

  • 标题条板块徽标（立体仓储 / RGV / 堆垛机）：点击按板块筛选，再点取消；板块按清单名关键词自动归类，可配置
  • 标题条等级徽标（P0 / P1 / P2 / P3）：点击按等级筛选，再点取消
  • 搜索框模糊匹配板块 / 清单 / 单号 / 供应商 / 采购员 / 物料 / 状态 / 预计日期（不区分大小写、不区分空格）
  • 筛选后清单卡片墙、标题条徽标与明细表会同步刷新
  • 清单卡片墙底部「查看更多」可加载后续清单（默认每页 20 条）

🖱️ 交互操作

  • 点击清单卡片：进入该清单，展示其下的各张采购单色块；点「← 返回全部清单」退回清单列表
  • 点击采购单色块：弹出该单详情（基础字段 + 物料明细 + 处理原因）；再次点击收起
  • 明细表行「展开明细」按钮：查看该单完整的物料 / 数量 / 已收数量 / 单价 / 单位
  • 点击标题条板块 / 等级徽标：快速按板块或等级筛选
  • 右上角全屏按钮 ⛶：进入 / 退出全屏，适合大屏监控
  • 所有操作只读，不会写回 Odoo
